# AppVellum

A job application tracking web application designed to help students and job seekers organise, manage, and monitor their job and internship applications in one centralised platform.

---

## Problem Statement

As a student and job seeker, I need a centralised platform to track and manage my job and internship applications, monitor the progress of each application, keep track of important dates and deadlines, and organise relevant information in one place. Without a centralised system, it can be difficult to keep track of multiple applications and their current statuses, which may lead to missed deadlines, forgotten follow-ups, or disorganised application information.

## Features

### Core Features

- User registration and authentication
- Dashboard displaying application statistics
- Add, edit, and delete job or internship applications
- Track application statuses (Applied, Interview, Offer, Rejected, etc.)
- Store company and job information
- Record important application deadlines
- Schedule and manage interviews
- Search and filter applications

## Architecture

AppVellum follows the **Model-View-Controller (MVC)** architectural pattern.

- **Model** – Represents the application's data and business logic.
- **View** – Displays information through the user interface.
- **Controller** – Handles user requests and coordinates communication between the Model and View.

## Getting Started

### Prerequisites

Before running this project, ensure you have the following installed:

- Visual Studio 2022
- .NET SDK
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/AppVellum.git
   ```

2. Navigate to the project directory:

   ```bash
   cd AppVellum
   ```

3. Open the solution in Visual Studio.

4. Configure the SQL Server connection string in `appsettings.json`.

5. Run the database migrations (if applicable).

6. Build and run the application.
